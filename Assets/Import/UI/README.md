# assets/ — нарезка спрайтов для Unity uGUI

PNG, прозрачный фон, **@2x** от макета 1080×1920. Число в имени файла = размер источника в 1x.
Импорт: **Texture Type** = Sprite (2D and UI), **Sprite Mode** = Single, **Pixels Per Unit** = 100,
**Compression** = RGBA Compressed, **Generate Mip Maps** = off, **Filter** = Bilinear.

Источник — `Sprite Sheet.dc.html`. Правки вносить там и снимать заново.

---

## Главное правило: спрайт — только подложка

Всё, что меняется кодом, **не запечено** в PNG и ставится сверху отдельными объектами:
цифры статов, чипы цветов, суммы и иконки валют, текст стикеров и кнопок, проценты скидок.
Спрайты дают рамку, риски, форму и износ — не контент.

| Спрайт | Что в PNG | Что ставится сверху в UI |
|---|---|---|
| `card_stat_plank_96x48` | рамка и две пунктирные риски, **без цветных полос** | иконки атаки/HP/скорости + три числа; цвет несут иконки |
| `card_cloth_banner_48x64` | тряпка с оборванным низом | чипы элементов (`card_element_chip_48`), по одному на цвет |
| `card_chip_fill_48` | белый круг | Color Tint = цвет элемента |
| `card_chip_ring_48` | белое кольцо | отдельный Image поверх заливки, Color Tint = тёмный тон элемента |
| `tag_price_64x48` | бирка с дыркой от гвоздя | иконка валюты + сумма |
| `sticker_*_64x40` | цветная/пунктирная подложка | текст TMP («NEW!», «−40%», «SOLD OUT»…) |
| `btn_*_64` | форма, блик, потёртый угол | подпись TMP; тень-дубль — **отдельный Image** +8/+8 |

Крены (−4°, +3°, −8°…) задаются Z-rotation у RectTransform, не в спрайте.
**Исключение:** ракурс монеты и крен банкноты запечены в иконку — их крутить нельзя,
иначе цифра стоимости поедет вместе с монетой.

## Свечение: legendary против exotic

| Файл | Размер | Как анимировать |
|---|---|---|
| `decor_sunburst_1024` | 1024² | **только legendary**, награды, результат матча. Вращать 40s, не более одного на экран |
| `decor_exotic_ring_outer_256` | 256² | **только exotic**. Белое, Color Tint #C24B33 alpha 85%. Вращать **по часовой**, 24s |
| `decor_exotic_ring_mid_224` | 224² | alpha 55%. Вращать **против часовой**, 18s |
| `decor_exotic_ring_inner_192` | 192² | alpha 30%. Вращать **по часовой**, 34s |

Лучей у exotic нет — именно отсутствие света отличает его от legendary на любом размере. Три кольца
крутятся в разные стороны с разной скоростью: это даёт «нездоровое» движение вместо праздничного
сияния. Основной же признак экзота на карте — полосатый кант (`decor_hazard_red_181x45`).

Все три кольца белые: цвет и alpha задаются Color Tint, поэтому под новый пародийный сеттинг
их можно перекрасить без перерисовки.
