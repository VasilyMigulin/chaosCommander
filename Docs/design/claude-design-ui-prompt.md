# Промт для Claude Design — полный UI игры «Горе-герои» / "Second-Hand Heroes"

> Как пользоваться: вставь всё, что ниже разделителя, одним сообщением в Claude Design.

> потом мета-экраны пачками (порядок приоритетов — в конце промта).

# ЗАДАЧА

Спроектируй полноценный UI-кит и высокодетальные макеты всех экранов мобильной коллекционной
карточной игры. Нужны: дизайн-система (токены, типографика, компоненты), покадровые макеты
экранов со всеми состояниями, лист рамок карт, иконографика. Игра уже работает — геймплей и
структура экранов зафиксированы, их менять нельзя; задача — дать всему этому цельный,
характерный визуальный язык.

# ИГРА В ДВУХ СЛОВАХ

**«Горе-герои»** (RU) / **"Second-Hand Heroes"** (EN — это не перевод, а своя шутка для своего
рынка). Сатирическая ККИ с боями на клетчатой доске: пародийное фэнтези про горе-героев,
барахолку и комиссионку. Тон — трэш-балаган в духе Epic Spell Wars: смешно, нагло, слегка
облезло, но дорого сделано. Первый аддон — сатира на киновселенную Marvel (Баклажанос и
«Стразы Бесконечности»), т.е. стиль должен масштабироваться под новые пародийные сеттинги.

- Платформа: Unity, мобильная, **портретная ориентация** (база 1080×1920, safe area обязательна).
- Аудитория: EN-рынок приоритетен, RU — второй язык. Все тексты локализуемые.
- Бой: 3D-доска в мире + UI-оверлей поверх. Мета (меню/магазины/коллекция) — чистый 2D UI.

## Ключевые правила геймплея (влияют на UI)

- Колода: **20 карт + 1 командир**. Командир всегда в руке в **отдельном слоте**; после его
  гибели — кулдаун 1 ход (слот должен уметь показывать «на поле / кулдаун N / готов»).
- Рука: **5 карт + командир**. Счётчик руки «x/6», счётчик колоды — просто число.
- Типы карт: **существа** (стоят золото, призываются на свой фронт-ряд), **заклинания** (мана),
  **чары** (мана; у игрока максимум **5 активных чар** — нужна полоса слотов чар, видимая обоим).
- Ресурсы: **золото** (базовая валюта хода: +1 к максимуму каждый ход, кап 10), **мана**,
  **HP аватара**. Иконки: монета / кристалл / сердце.
- Доска: две зеркальные половины **2 ряда × 5 колонок** на игрока (шахматная раскраска клеток)
  + по **аватар-клетке** позади каждой стороны. Row 0 = фронт. Атаковать аватара можно только
  прорвавшись на половину врага — подсветка аватар-клетки как цели важна.
- Статы существ: **атака / здоровье / скорость** (скорость подписываем «скр» / "spd", не «ход»).
- Редкости (это ось СИЛЫ и лимит копий, не частота дропа): Common 4 копии / Rare 3 / Epic 2 /
  Legendary 1 / Exotic 1 (экзот — 1 на всю колоду). Пять рамок/баннеров редкости.
- Элементы карт — 6 цветов-флагов: Red, Blue, Green, Yellow, White, Black (карта может иметь
  несколько). Нужны компактные элемент-индикаторы на рамке.
- Есть карты-с-уровнями (растут за матч) — рамке нужен «тир-стейт» и баннер «карта выросла».

## Язык оформления («трэш-балаган»)

- Лучи-санберст за героями/наградами, halftone-растр в подложках.
- «Опасные» диагональные полосатые ленты как разделители/акценты.
- Панели и стикеры с лёгким креном ±1.5° — ничего идеально ровного.
- Стикеры/печати/штампы («NEW!», «SALE», «СЛОМАНО»), потёртости, ценники-бирки.
- Бегущая строка (marquee) как декоративный элемент (названия карт, «новости барахолки»).
- Мотив карточных мастей ♠ ♦ ♥ + ★ для командира. **ВАЖНО: никаких шахматных фигур и
  шахматной атрибутики в брендинге** — доска/клетки в бою можно, ферзи/пешки в UI — нельзя.

## Типографика

- Заголовки: сверхжирный гротеск, UPPERCASE, допускается лёгкий наклон/варп. Обязательна
  полная кириллица (в движке сейчас Roboto Bold SDF; если предлагаешь пару шрифтов —
  только с кириллицей и свободной лицензией, без веб-CDN).
- Служебный текст/цифры/таймеры: моноширинный.
- RU-строки в среднем на 30–40% длиннее EN — вёрстка обязана это выдерживать.
- Тексты на макетах делай **на английском** (приоритетный рынок), но 2–3 ключевых экрана
  продублируй с русскими строками для проверки вёрстки.

## Тон текстов

Сатира, самоирония, барахолочный вайб. EN шутит про комиссионку ("sold as seen", "as is",
flea-market economics), RU — про барахолку и «горе-». Никакого пафоса ККИ-жанра. На макетах —
живые тексты в этом тоне, не lorem ipsum.

# ГЛОБАЛЬНЫЕ UI-ПАТТЕРНЫ (архитектура уже в коде — соблюдать)

1. **Персистентный HUD меню**: верхний бар (плашка профиля: аватар, ник, уровень, валюты +
   кошелёк) и **нижняя таб-бара на 6 вкладок**: Играть / Бустеры / Магазин / Чёрный рынок /
   Журнал / Аукцион. Контент-экраны свапаются между барами. У вкладок есть состояние
   «активна» и **бейдж «новое»** (точка/стикер).
2. Навигация со стеком «назад» (Android back / iOS свайп от левого края) — у всех вложенных
   экранов кнопка «назад» в едином стиле.
3. **Тосты** 4 типов: Info / Success / Reward (с иконкой награды) / Warning — верхний оверлей,
   виден поверх и меню, и боя.
4. **Диалог подтверждения** (единый компонент): покупки, продажи, выход из боя.
5. **Попап награды** «Вы получили» (карта/валюта, glow по редкости) и **очередь входящих
   сообщений** (inbox: заголовок + текст + награды, кнопка ОК → следующее).
6. **Гейт версии**: блокирующий оверлей «Обнови игру» с кнопкой в стор.
7. Грейинг по деньгам: кнопки покупки тускнеют, если не хватает валюты.
8. Тач-таргеты ≥ 48dp, нижняя треть экрана — зона большого пальца для главных действий.

# ИНВЕНТАРЬ ЭКРАНОВ

Для каждого экрана нужны: макет + состояния (загрузка / пусто / офлайн-ошибка / длинные строки).

## A. Онбординг

**A1. Выбор языка** — первый экран первого запуска. Крупные кнопки языков (RU/EN,
масштабируется на новые), логотип, настроение «добро пожаловать на барахолку».

**A2. Знакомство (логин)** — тихий гостевой вход (спиннер) → панель «Давай знакомиться» /
"Let's get acquainted": поле ника (3–25 символов), кнопка «Продолжить», кнопки Google/Apple
в состоянии disabled со стикером «скоро», мелкая кнопка «Уже есть аккаунт» (вход почтой).
Состояния: спиннер входа, офлайн (плашка + Retry), ошибка ника.

**A3. Туториал (оверлей боя)** — плашка-подсказка с текстом шага + кнопка «Далее» для
инфо-шагов; будущий спотлайт (затемнение всего, кроме подсвеченной зоны + рамка). 11 шагов,
тон шуточный.

## B. Мета (меню)

**B1. Домашний экран (Главное меню)** — блок профиля (аватар, ник, уровень + XP-полоса,
ранг/MMR), большая CTA «Играть», вход в Колоды и Настройки. Это витрина игры — сюда весь
трэш-балаган: санберст, стикеры, бегущая строка.

**B2. Выбор режима** — PvP (рейтинговый матчмейкинг) / PvE (кампания). Две большие карточки
режимов.

**B3. Поиск соперника** — статус поиска (анимация), подбор по MMR, кнопка отмены,
переход в загрузку боя + VS-заставка (два командира лицом к лицу).

**B4. Карта кампании (стори-мод)** — вертикальная карта из 6 боёв сюжета «Шальной принц
спасает Распрекрасную принцессу от Гнидальфа немытого»: Побег из замка → Канализация →
Качалка → Болото невезения → Преисподняя → Логово Гнидальфа. Узлы: пройден / доступен /
заблокирован; у узла — портрет босса и превью награды (карты).

**B5. Коллекция + колодостроитель** — самый сложный мета-экран. Сетка карт коллекции с
фильтрами (тип / элемент / редкость / стоимость / владение), панель текущей колоды
(20 слотов + отдельный слот командира ★), счётчики копий с лимитом по редкости (4/3/2/1/1),
индикация «карт не хватает». Long-press по карте → **B6**.

**B6. Попап карты (инспект)** — крупная карта + полное описание + список «связанных» карт
(кого призывает/создаёт). Вызывается отовсюду: коллекция, бой, история розыгрышей.

**B7. Профиль** — шапка (аватар, ник, ранг/MMR) + строки статистики: победы, поражения,
винрейт, игры, достижения, бустеры, карты.

**B8. Настройки** — язык, звук/музыка, раздел «ID для входа на сайте» (показать/скопировать
device ID, тост «скопировано»), версия игры, выход из аккаунта.

**B9. Журнал (daily/weekly)** — вкладка задач: карточки задач с прогресс-баром и кнопкой
«Забрать» (12 типов задач: сыграй карты, убей существ, выиграй игры и т.п.), таймеры до
сброса (daily) и до среды (weekly); лента входных наград на 7 дней (день N подсвечен).

**B10. Магазин** — витрина: бустеры, аватары, наборы. Ценники-бирки, стикеры скидок,
подтверждение покупки, грейинг при нехватке валюты. Кошелёк виден всегда.

**B11. Бустеры + вскрытие** — полка паков с количеством; флоу вскрытия: пачка по центру →
тап → разрыв/burst → карты веером с эффектным stagger, glow по редкости (rare+ ярче),
кнопка «Забрать всё». Это должен быть самый сочный момент меты.

**B12. Чёрный рынок** — ротируемая витрина карточных офферов (структура ротации:
4 common / 3 rare / 2 epic / 1 legendary / 1 exotic), таймер до ротации (среда), правило
«купил одну — остальные заблокированы до ротации» (нужно состояние lockout со стикером
типа «РАСПРОДАНО»). Вайб — тёмный угол барахолки, самое сатирическое место игры.

**B13. Аукцион** — две вкладки: «Лоты» (список чужих листингов: карта, цена, кнопка купить)
и «Мои» (мои листинги + выставить свою карту: диалог цены с комиссией). Состояния: пусто,
мой лот, чужой недоступный по деньгам.

**B14. Inbox / попап «Вы получили»** — см. глобальные паттерны; отрисовать конкретные макеты.

## C. Бой (портрет; 3D-доска, UI — оверлей)

**C1. Боевой HUD (главный экран игры)** — раскладка сверху вниз:
- Верх: аватар оппонента + его статы (HP/золото/мана/рука/колода — компактно над аватаром),
  полоса чар оппонента (до 5 иконок), таймер хода.
- Центр: доска (4 ряда × 5 колонок суммарно + 2 аватар-клетки) — UI не должен её перекрывать;
  подсветки клеток: ход / атака / цель-аватар / выбор клетки призыва.
- Низ: полоса чар игрока, ресурс-панель локального игрока (HP, золото x/max, мана,
  рука x/6, колода), веер руки из 5 карт + **слот командира** (отдельный, со звездой;
  состояния: готов / на поле / кулдаун N), кнопка **«Конец хода»** (главная CTA боя;
  состояния: мой ход / ход врага / горит таймер).
- Розыгрыш перетаскиванием «карта под пальцем»: превью карты над пальцем + подсветка
  валидных целей; у заклинаний — прицельная стрелка.
- Баннер «карта выросла» (тир-ап) — краткий шоу-стоппер.
- Счётчик «Стразов» у аватара (коллекция из 6 камней, виден обоим) — задел под аддон.

**C2. Старт матча** — оверлей загрузки, VS-заставка, мулиган (выбор карт стартовой руки:
карты с «оставить/заменить», таймер, кнопка подтверждения).

**C3. Фид розыгрышей + история** — слайд-ин плашка «кто что разыграл» (мини-карта + имя
игрока), и **свайп-дровер слева**: лента миниатюр последних разыгранных карт, long-press
по миниатюре → попап карты B6.

**C4. Окно выбора карт (PickupWindow)** — одно окно на 4 сценария: «раскопка» (выбор 1 из 3),
выбор карты из колоды/руки/кладбища, замена добора. Варианты: с кнопкой отмены и
обязательный (без отмены). Таймаут в конец хода.

**C5. Диалоги сюжета («говорящие головы»)** — портрет персонажа сбоку, имя, реплика,
очередь реплик с фейдами; появляется на интро боя, по скриптовым событиям посреди боя
и на исходе. Не блокирует доску дольше необходимого.

**C6. Флоу конца матча** — три стадии одним окном/цепочкой:
1) Результат: ПОБЕДА / ПОРАЖЕНИЕ / НИЧЬЯ (крупно, с характером: победа — санберст и конфетти
   из хлама, поражение — стикер «СЛОМАНО»),
2) Рейтинг: дельта MMR (+25 / −18) со спиннером ожидания и состоянием «покажем позже»,
3) Награды: золото за матч, карты (за PvE), закрытые задачи журнала с кнопкой «Забрать».
Кнопка «В меню».

## D. Лист карт (отдельная поставка!)

Рамки для всех типов и состояний:
- Существо (атака/HP/скр + стоимость-золото), заклинание (стоимость-мана), чара
  (стоимость-мана), токен (упрощённая рамка), командир (★-акцент).
- 5 баннеров редкости (Common/Rare/Epic/Legendary/Exotic) — читаемы на миниатюре.
- 6 элемент-индикаторов (R/B/G/Y/W/Black), включая мультиэлемент.
- Тир-состояния растущих карт (уровень 1/2/3 — рамка «прокачивается»).
- Рубашка карты (мотив мастей + брендинг).
- Размеры: полноразмер (инспект), рука, миниатюра фида/истории, слот колодостроителя.

# ТЕХНИЧЕСКИЕ ОГРАНИЧЕНИЯ

- Реализация: Unity uGUI + TextMeshPro. Панели — 9-slice-friendly (тянущиеся рамки),
  эффекты — спрайты/маски, **без** рантайм-блюров и тяжёлых шейдеров в UI.
- Никаких вебшрифтов/CDN: шрифты либо системные, либо встраиваемые SDF с кириллицей.
- Анимации — DOTween-простые: fade/scale/slide, крены, пружинки. Указывай в макетах
  какие элементы анимируются и как.
- Все строки локализуемые (ключи ui.*), вёрстка переживает RU +40% длины.
- Тёмная тема единственная; контраст текста — AA на грунте `#0B090E`.

# ЧЕГО НЕ ДЕЛАТЬ

- Не менять геймплей, состав экранов и навигацию — только визуальный слой.
- Никаких шахматных фигур, «ККИ × шахматы» в брендинге.
- Никаких настоящих имён/логотипов Marvel — только собственные пародии (Баклажанос /
  Eggplanos, Стразы Бесконечности / Rhinestones of Infinity).
- Без фотореализма, глянцевого «мидкор-фэнтези» и стерильного flat — только трэш-балаган.
- Без светлой темы, без lorem ipsum.

# ПОРЯДОК РАБОТЫ И ФОРМАТ ПОСТАВКИ

1. **Дизайн-система**: токены (цвета/типографика/отступы/радиусы/тени), базовые компоненты
   (кнопки 3 уровней + disabled, поля, табы, бейджи, тосты, диалог, прогресс-бары, таймеры,
   ценник, стикеры).
2. **Лист карт (D)** — от него зависит всё остальное.
3. **Боевой HUD (C1)** + старт/конец матча (C2, C6).
4. **Домашний экран + таб-бара (B1)** и коллекция (B5, B6).
5. Остальная мета пачками: журнал/магазин/бустеры → рынок/аукцион → онбординг → диалоги
   сюжета и окна выбора.

По каждому экрану: макет 1080×1920 + перечисление состояний + аннотации (что анимируется,
что тап/лонг-пресс/свайп). После каждой пачки — стоп на фидбек, дальше не бежать.
