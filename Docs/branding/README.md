### Как вырезали фон

Исходник пришёл PNG на чёрном фоне. Простое «удалить чёрный» не годится — вместе с фоном
пропадают чёрные брови и зрачок. Правильный способ — **заливка от краёв кадра**: прозрачным
становится только та тёмная область, что связана с рамкой, а всё внутри силуэта остаётся.
Скрипт (одноразовый, лежал в scratchpad) делал: заливку с допуском, мягкую кромку с
восстановлением цвета по формуле `true = (observed − bg·(1−a)) / a`, обрезку полей и
даунскейл усреднением по площади. Если понадобится повторить для новой картинки — попроси,
соберу заново; библиотека `pngjs`, чистый JS, без нативных зависимостей.

Посмотреть все три рядом и в мелких размерах: открыть `icons-preview.html` в браузере.

## Перегенерировать PNG

Нужен только браузер на Chromium (Edge стоит в Windows по умолчанию). Из этой папки:

```powershell
$edge = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
$dir  = $PWD.Path
foreach ($n in 'bucket','gnidalf','card') {
  "<!doctype html><meta charset='utf-8'><style>html,body{margin:0;overflow:hidden}img{display:block;width:1024px;height:1024px}</style><img src='icon-$n.svg'>" |
    Set-Content "$dir\_export.html" -Encoding utf8
  & $edge --headless=new --disable-gpu --hide-scrollbars --allow-file-access-from-files `
          --default-background-color=00000000 --virtual-time-budget=4000 `
          --window-size=1024,1024 --screenshot="$dir\png\icon-$n-1024.png" "file:///$($dir -replace '\\','/')/_export.html"
}
Remove-Item "$dir\_export.html"
```

Меняя `--window-size` и имя файла, получаешь любой размер (512, 256, 192, 128, 64).
Углы в PNG прозрачные — магазины приложений скругляют иконку сами.

## Куда ставить

- **Unity:** Project Settings → Player → Icon. Перетащить PNG в проект, в импортере
  поставить Texture Type = **Sprite (2D and UI)** или Default, снять Generate Mip Maps,
  и назначить в слоты Default / Adaptive.
- **Сайт:** `website/public/favicon.svg` — там лежит упрощённое ведро (без лучей и ценника,
  иначе на 16 px каша). Правя иконку, правь и его.
