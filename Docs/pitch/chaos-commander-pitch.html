Позиционирование

Знакомый жанр + недостающее измерение

Знакомый вход

Луп ККИ, который аудитория знает наизусть: колода, рука, мулиган, стоимость карт, баттлкраи и предсмертные эффекты. Порог входа — нулевой для игрока Hearthstone / Marvel Snap.

Новая глубина

Существа выходят на доску 2×5 и двигаются: скорость — ресурс хода, атака по аватару — только прорвавшись на заднюю линию врага. Каждый размен — позиционное решение, а не «трейд в лицо».

Тон, который запоминается

Трэш-комедийное фэнтези: Работяги со стройки, Черти, Гнидальф и Шальной принц. Карты вроде «Прикурить!» и «Чёрная бухгалтерия» — сеттинг сам продаёт скриншоты.

Разыграть

Карты за золото; существа — на свою заднюю линию

Манёвр

Движение по клеткам в пределах скорости — в один клик по маршруту

Прорыв

Дойти до задней линии врага и бить аватара

  • Доска 5×2 на каждую сторону, встречный фронт по центру
  • Два ресурса: золото растёт по ходам, мана — только за убийства: агрессия буквально оплачивает сильные карты
  • Командир — карта-герой: гибнет на доске → возвращается в руку с кулдауном, а не проигрывает партию
  • Чары — третий тип карт: постоянные эффекты на поле со своим статус-баром и таймерами

Технология

Фундамент, который не придётся переписывать

  • Unity 6, геймплей на ECS (LeoECS Lite) — правила отделены от визуала, новые карты собираются в редакторе из готовых «кирпичей»-эффектов без программиста
  • Детерминированный синк: активный клиент играет, пассивный воспроизводит снапшоты действий — реплеи и спектейт-режим достаются почти бесплатно
  • Photon Fusion — матчмейкинг и реалтайм PvP уже работают
  • PlayFab Economy v2 + Azure Functions — серверная экономика заложена: инвентарь, каталог, валюты
  • Пайплайн локализации: CSV → Unity Localization, вся карта-верстка через шаблонизатор
Почему это важно издателю

Стоимость добавления контента низкая: карта = ассет из готовых компонентов + две строки локализации. Команда масштабирует контент без роста кодовой базы. Технический риск проекта — уже позади; остался визуальный продакшн.
